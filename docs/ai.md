# AI

## Scope

Track public-safe AI agent configuration and workflow notes for this repo.

## In scope

- agent operating rules
- prompts and reusable instructions
- schemas and examples
- reviewed config for tools such as Codex, Claude Code, Cursor, Hermes, and OpenCode

## Out of scope

- provider API keys
- OAuth files
- chat exports containing private material
- browser profiles or cookies

## Cleanup direction

- keep `ai/` limited to rules, prompts, skills, schemas, and examples
- move non-AI utility scripts out of `ai/`
- review AI tool config before moving it under `config/` or `stow/`
